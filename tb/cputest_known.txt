# Known deviations of the cputest oracle (WinUAE) from the 68060, where the
# core follows the manual or the M68060SP (doc/STATUS.md).  One per line:
#   <slice-name glob> <regex on a round's first mismatch>  <reason>
# run_cputest.py --known reports a slice as KNOWN when every failing round's
# first mismatch (as its log lists them) matches one of these.
#
# denormal/unnormal FP source: format $0 frame (6.5.2), WinUAE $3
PackedFPU--*     exception\sframe:\sexpected\s00000030\sgot\s00000000   denormal-source-frame
FILLG--*.S--*    exception\sframe:\sexpected\s00000030\sgot\s00000000   denormal-source-frame
FILLG--*.D--*    exception\sframe:\sexpected\s00000030\sgot\s00000000   denormal-source-frame
# unimplemented FP instruction, extended -(An): EA = An - 12 + 8, An kept
# (M68060SP _dcalc_ea); WinUAE An - 12
FILLG--*.X--*    exception\sframe:\sexpected\s000000[0-9a-f]{2}\sgot        unimp-ext-predec-ea
# unimplemented integer instructions (CAS misaligned, CAS2, CHK2/CMP2,
# 64-bit MULL/DIVL, MOVEP): vector 61 for the M68060ISP; a corpus generated
# with cpu_no_unimplemented=0 executes them
*--CAS*          got\s0000003d                                         unimp-integer
*--CHK2*         got\s0000003d                                         unimp-integer
*--CMP2*         got\s0000003d                                         unimp-integer
*--DIVL.L*       got\s0000003d                                         unimp-integer
*--MULL.L*       got\s0000003d                                         unimp-integer
*--MVP*          got\s0000003d                                         unimp-integer
# ... and their traced rounds (the Default group): the generator's trace
# after the instruction it executes, where the core took vector 61
*--CAS*          missing\strace                                        unimp-integer
*--CHK2*         missing\strace                                        unimp-integer
*--CMP2*         missing\strace                                        unimp-integer
*--DIVL.L*       missing\strace                                        unimp-integer
*--MULL.L*       missing\strace                                        unimp-integer
*--MVP*          missing\strace                                        unimp-integer
# ODD_EXC/ODD_IRQ: every vector from 4 up holds the odd address $123
# (feature_exception_vectors), so any exception ends in an address error
# (vector 3, stacked PC = the vector's offset).  In rounds with a trace bit
# set the generator does not take the trace after the instruction under
# test: it stores the trace SR/PC (the "standalone trace" record) and runs
# on to the terminating ILLEGAL, whose vector 4 faults (stacked PC $10).
# A 68060 takes the trace first, and its vector 9 faults (stacked PC $24,
# WinUAE's own model of the fault: regs.pc = vector * 4), so no round of
# this kind can replay against the record (the native tester's 68020+
# handlers have no resume for it either).  Rounds without a trace bit
# pass in full.
ODD_EXC--*       missing\strace                                        traced-sequence
ODD_IRQ--*       missing\strace                                        traced-sequence
# MOVEC2: rounds writing TCR/BUSCR across traced sequences (DWO, SL/SLE):
# a traced MOVEC Dn,BUSCR with L and LE set reads back SL and SLE after
# the trace exception (7.4: L/LE copied to SL/SLE and cleared); the
# generator's trace-free sequence reads L and LE
*--MOVEC2--*     execution\stimeout                                    traced-sequence
*--MOVEC2--*     D\d:\sexpected\sa0000000\sgot\s50000000                 traced-sequence
